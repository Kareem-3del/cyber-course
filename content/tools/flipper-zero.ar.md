# Flipper Zero — الدليل التشغيلي المتكامل للمحللين

يُعد جهاز Flipper Zero أداة محمولة متعددة المهام مخصصة لاختبار الاختراق والأبحاث الميدانية. يجمع الجهاز بين عدة تقنيات في منصة واحدة: راديو sub-GHz (بترددات 433/315/868/915 ميغاهرتز)، وتقنية NFC (13.56 ميغاهرتز)، وRFID (125 كيلوهرتز)، والأشعة تحت الحمراء (Infrared)، وبروتوكول iButton (1-Wire)، بالإضافة إلى واجهات GPIO ومحاكاة أجهزة الإدخال (USB HID). يمثل الجهاز عتاداً مثالياً لاستنساخ بطاقات الدخول، وإعادة بث إشارات الأشعة تحت الحمراء، وتنفيذ هجمات BadUSB، وإجراء أبحاث الترددات اللاسلكية (RF) قصيرة المدى.

> [!warning] الإطار القانوني والتنظيمي
> تخضع عمليات الإرسال عبر نطاق sub-GHz (مثل مفاتيح السيارات وأبواب المرائب) لتنظيمات صارمة في معظم الدول. يجب الالتزام بنطاقات الهواة أو النطاقات غير المرخصة، وقصر الاختبارات على الأجهزة المملوكة لك أو المصرح لك باختبارها. قامت دول مثل البرازيل وكندا وأستراليا وهولندا بفرض قيود على بيع الجهاز أو بعض ميزاته.

## الإقلاع والبرامج الثابتة (Firmware)

البرنامج الثابت الافتراضي: **Flipper Zero Stock**. الخيارات المجتمعية المتقدمة:
- **Momentum** (سابقاً Xtreme): الخيار الأكثر نشاطاً وتوازناً بين الميزات والقواعد الرسمية.
- **RogueMaster**: يوفر ميزات متقدمة جداً ولكن بواجهة وتجربة مستخدم أقل استقراراً.
- **Unleashed**: خيار متوسط يركز على إزالة القيود الإقليمية (Region-restriction removal).

يتم تحديث البرنامج الثابت عبر تطبيق qFlipper أو محدّث الويب (Web Updater).

## تطبيقات القائمة الرئيسية

| التطبيق | الاستخدام التشغيلي |
|-----|-----|
| **Sub-GHz** | التقاط وإعادة بث إشارات RF، وتنفيذ هجمات القوة العمياء (Brute-force) لمفاتيح التحكم |
| **125 kHz RFID** | استنساخ بطاقات EM4100 و HID Prox (المستخدمة بكثرة في شارات المكاتب) |
| **NFC** | التعامل مع بطاقات MiFare Classic و Ultralight و DESFire و NTAG |
| **Infrared** | تعلم محاكاة أجهزة التحكم عن بعد (التلفاز، أجهزة العرض، المكيفات) |
| **iButton** | محاكاة مفاتيح 1-Wire (مفاتيح Dallas) |
| **Bad USB** | تنفيذ سيناريوهات حقن ضربات المفاتيح (Keystrokes) وحمولات Ducky |
| **U2F** | محاكاة مفاتيح التحقق (بشكل محدود؛ عبر تدفقات TOTP) |
| **GPIO** | استخدام المحلل المنطقي (Logic Analyzer) وواجهات UART و SPI |
| **Apps catalog** | الوصول إلى متجر تطبيقات Flipper الرسمي |

## سيناريوهات العمل الشائعة

### استنساخ شارات الـ RFID (تردد 125 كيلوهرتز)

1. الانتقال إلى RFID ← Read.
2. تقريب الجهاز من الشارة لمسافة ~3 سم.
3. عند اكتشاف نظام "EM4100" أو "HIDProx" ← يتم الحفظ باسم `office`.
4. للمحاكاة: RFID ← Saved ← اختيار `office` ← Emulate، ثم التقريب من القارئ.

معظم أنظمة الدخول القديمة يمكن استنساخها في ثوانٍ معدودة. أما الأنظمة الحديثة (مثل HID iCLASS SE) فلا يمكن تجاوزها باستخدام البرنامج الثابت الافتراضي للجهاز.

### التقاط وإعادة بث إشارات Sub-GHz

1. الانتقال إلى Sub-GHz ← Read RAW (أو Frequency Analyzer).
2. الضغط على مفتاح التحكم بالقرب من جهاز Flipper.
3. حفظ الإشارة الملتقطة.
4. لإعادة البث: Sub-GHz ← Saved ← Send.

ملاحظة: أنظمة التحكم الحديثة التي تستخدم الأكواد المتغيرة (Rolling-code) لن تستجيب لإعادة البث البسيط، بينما تنجح العملية تماماً مع الأنظمة القديمة ذات الكود الثابت (Static-code).

### محاكاة أجهزة التحكم بالأشعة تحت الحمراء (IR)

1. Infrared ← Universal Remote (TV/AC/Audio) — تجربة الأكواد الشائعة للمصنعين.
2. في حال فشل التجربة ← Learn ← توجيه جهاز التحكم الأصلي نحو Flipper والضغط على الزر المراد برمجته.
3. الحفظ ثم إعادة البث (Replay).

### هجمات حقن ضربات المفاتيح (BadUSB)

يتم وضع سكربت بصيغة نصية `.txt` (باستخدام قواعد Rubber-Ducky) على بطاقة الذاكرة في المسار `badusb/`:

```
DELAY 1000
GUI r
DELAY 500
STRING powershell -nop -w hidden -ec <BASE64>
ENTER
```

عند توصيل الجهاز بمنفذ USB الخاص بالضحية ← الانتقال إلى Apps ← Bad USB ← تشغيل السكربت. يتعامل النظام مع الجهاز كلوحة مفاتيح شرعية.

### التعامل مع تقنية NFC — MiFare Classic

1. NFC ← Read.
2. إذا كانت البطاقة من نوع MFC وتستخدم مفاتيح افتراضية، سيقوم الجهاز باسترداد البيانات تلقائياً.
3. للمفاتيح غير الافتراضية، يتم استخدام أداة `flipper-mfkey32` على الحاسوب لتنفيذ هجوم القوة العمياء على ملف `.nfc` المستخرج.

لا يمكن كسر تشفير بطاقات DESFire EV1+/EV2 أو NTAG 424 DNA باستخدام جهاز Flipper بمفرده.

## فحص العتاد عبر واجهة GPIO

- يوفر الجهاز 8 دبابيس GPIO تعمل بجهد 3.3 فولت.
- تطبيق "GPIO" يسمح بالتحكم في الدبابيس وقراءتها.
- تطبيق "USART" يوفر طرفية UART للاتصال التسلسلي.
- تطبيق "SPI Mem Manager" يستخدم لسحب محتويات ذاكرة الوميض (Flash Dump) من رقاقات SPI.

حالات الاستخدام: سحب البرنامج الثابت (Firmware) لأجهزة الراوتر أو إنترنت الأشياء (IoT) عبر واجهة SPI عندما تكون واجهة JTAG مغلقة.

## تطبيقات إضافية يوصى بها

- **Picopass**: لتوسيع قدرات قراءة بطاقات iCLASS (يتطلب تعديل عتاد بسيط).
- **Subghz Bruteforcer**: لتنفيذ هجمات القوة العمياء على الأكواد الثابتة.
- **Mifare Fuzzer**: لاختبار مفاتيح قطاعات بطاقات Mifare.
- **WiFi Marauder**: عند استخدام لوحة ESP32 خارجية لتنفيذ هجمات Deauth واستطلاع الشبكات اللاسلكية.

## استكشاف الأخطاء وإصلاحها

| العرض | الحل المقترح |
|---------|-----|
| فشل قراءة RFID | تأكد من نطاق التردد (HF vs LF)؛ إذا كانت البطاقة 13.56 ميغاهرتز استخدم تطبيق NFC |
| إعادة بث Sub-GHz لا تعمل | النظام يستخدم كوداً متغيراً (Rolling code)؛ إعادة البث البسيط لن تجدي نفعاً |
| إدخال BadUSB يظهر رموزاً خاطئة | إعدادات لوحة المفاتيح غير متوافقة؛ يتم الضبط عبر `Settings → Keyboard layout` |
| فشل قراءة مفاتيح NFC الافتراضية | البطاقة ليست من نوع MFC، أو تم تغيير مفاتيحها؛ استخدم أداة mfkey32v2 |
| الجهاز متوقف تماماً (Bricked) | اضغط على زر L أثناء التوصيل بالـ USB للدخول في وضع DFU، ثم أعد التحديث عبر qFlipper |

## منظور المدافع (Defender's Perspective)

- عمليات استنساخ بطاقات Prox 125 كيلوهرتز غير مرئية لمعظم القارئات بسبب غياب آليات مكافحة الاستنساخ.
- التوصية الأمنية للمؤسسات: الانتقال إلى تقنيات HID Mobile Access أو MiFare DESFire أو LEAF وحظر أنظمة Prox تماماً.
- لمواجهة حقن USB HID: تفعيل سياسات (GPO) لحظر جميع فئات التخزين القابلة للإزالة، وتعطيل المنافذ الفيزيائية في الأماكن الحساسة.
- حماية أنظمة IR: عزل غرف التحكم فيزيائياً أو استخدام أجهزة استقبال مشفرة.
- حماية أنظمة Sub-GHz: الاعتماد الحصري على الأكواد المتغيرة وإيقاف استخدام أجهزة التحكم ذات الكود الثابت.

## الأمن التشغيلي (OPSEC)

- يقوم بلوتوث الجهاز ببث اسم "Flipper [name]"، مما يجعله مرئياً لأي عملية مسح. يجب تعطيله أثناء العمليات الميدانية.
- عمليات الإرسال غير القانونية عبر sub-GHz تترك أثراً يمكن تتبعه لاسلكياً.
- احرص على حمل بطاريات إضافية ونسخ احتياطية لبطاقة الذاكرة؛ الجهاز أداة عملياتية ويجب التعامل معه بحذر.
