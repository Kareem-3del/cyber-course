# دليل استخدام Canarytokens — الدليل الكامل

تُعدّ **Canarytokens** (من شركة Thinkst) بمثابة "كمائن تنبيهية" أو أسلاك تعثر (Tripwires) يتم زرعها عبر بيئتك التقنية. بمجرد أن يلمسها شخص ما أو يحاول الوصول إليها، يتم إرسال تنبيه فوري عبر البريد الإلكتروني أو الـ Webhook. تتوفر الخدمة مجانًا عبر `canarytokens.org`؛ كما يمكن الاستضافة الذاتية للنسخة مفتوحة المصدر (OSS) من خلال (`thinkst/canarytokens`) في البيئات الحساسة.

## أنواع التوكنز (Token types)

| التوكن (Token) | ماهيته | يُفعّل التنبيه عند... |
|-------|------------|-------------|
| **DNS / Web** | رابط (URL) أو اسم مضيف (Hostname) | أي محاولة لحل اسم النطاق (DNS resolution) أو زيارة الرابط |
| **Adobe PDF** | ملف PDF يرسل إشارة تنبيه عند فتحه | فتح ملف الـ PDF |
| **MS Word / Excel / PowerPoint** | مستندات Office تحتوي على تتبع | فتح المستند (يكشف عن عنوان الـ IP الخاص بالمصدر) |
| **AWS Access Key** | زوج مفاتيح وصول (AKIA / SK) وهمي | استخدام المفاتيح في أي طلب (API call) لـ AWS |
| **Azure Login Cert** | مفتاح لـ Service-principal | استخدامه للمصادقة في بيئة Azure |
| **Slow Redirect** | رابط يحوّل المستخدم لكنه يرسل تنبيهًا أولاً | الضغط على الرابط |
| **Cloned Website** | كود JS يُفعّل إذا كان النطاق لا يطابق الأصلي | قيام مهاجم باستنساخ صفحة تسجيل الدخول (Phishing) |
| **Signed EXE / DLL** | ملف تنفيذي أو مكتبة Windows متبوعة | تشغيل الملف |
| **HTTP File / Folder** | رابط ويب يمثل ملفًا أو مجلدًا وهميًا | زيارته |
| **MySQL Dump** | ملف SQL يرسل تنبيهًا عند استيراده | محاولة استيراد قاعدة البيانات |
| **Kubeconfig** | إعدادات k8s وهمية | محاولة المصادقة مع واجهة (API) وهمية |
| **WireGuard / SSH key** | بيانات اعتماد وهمية | استخدام المفاتيح |
| **MS SQL token** | إجراء مخزن (Stored procedure) | استدعاء الإجراء |
| **Custom HTTP** | رابط مع استجابة `Host` مخصصة | أي طلب من نوع GET |
| **Webhook only** | مجرد رابط (URL) بدون ملفات | أي طلب من نوع GET |

## سير العمل (Workflow)

### إنشاء توكن (الخدمة العامة)

عبر `canarytokens.org` ← اختر النوع ← أدخل البريد الإلكتروني للتنبيه ← أضف ملاحظة تذكيرية ← توليد (Generate). ثم ضع التوكن في أماكن استراتيجية:

- **مفاتيح AWS**: في ملفات `.env` أو سياسات S3 أو مستودعات README أو حسابات IAM المهجورة.
- **ملفات PDF**: في المجلدات المشتركة بأسماء مغرية مثل `passwords.pdf` أو `salaries.pdf`.
- **مستندات Office**: في مجلدات الموارد البشرية (HR) أو مجلدات الإدارة العليا.
- **DNS**: كـ CNAME أو اسم مضيف مشار إليه في ملف إعدادات (Config file).
- **Custom HTTP**: في إعدادات تطبيق داخلي، حيث لا يتوقع وصول أحد سوى "المتسللين" (Insiders).

### الاستضافة الذاتية (للمشاريع الحساسة)

```terminal
git clone https://github.com/thinkst/canarytokens-docker
cd canarytokens-docker
cp .frontend.env.template .frontend.env
# تحرير متغيرات البيئة
docker compose up -d
```

يتيح لك هذا إصدار التوكنز عبر نطاقك الخاص، مما يمنح المدافع سيطرة كاملة على بيانات التنبيه.

### استلام التنبيهات

تصل التنبيهات عبر البريد الإلكتروني أو الـ Webhook وتتضمن:

- عنوان الـ IP المصدر، ونسخة المتصفح (User-Agent).
- الموقع الجغرافي (Geolocation) - تقديري.
- النطاق الذي تمت محاولة حله (في توكنز DNS).
- اسم العملية (Process name) - في بعض الحالات، مثل مفاتيح AWS التي توضح أي API تمت مناداته.

## أمثلة تطبيقية

### نمط "فتات الخبز" (Strewn breadcrumbs)

نثر التوكنز في أماكن جذابة للمهاجمين:

| الموقع | نوع التوكن | دلالة التنبيه |
|----------|------------|-----------|
| `/etc/passwords-backup/credentials.pdf` | PDF | مهاجم يحاول قراءة نظام الملفات |
| `~/.aws/old-creds` | مفاتيح AWS | مهاجم يبحث عن مفاتيح سحابية |
| `\\fileserver\HR\salaries-2025.xlsx` | Excel | موظف داخلي يحاول التجسس |
| مدخل في مدير كلمات المرور باسم "DA — backup" مع ملف `runonce.exe` وهمي | ملف EXE موقع | مهاجم يجرب كافة بيانات الاعتماد |
| `git/.bash_history` يحتوي على `mysql -u root -pSuperSecret` (token-MySQL) | MySQL dump | مهاجم ينسخ سجل الأوامر |

**الهدف**: ضمان تفعيل تنبيه واحد على الأقل في أي مسار هجوم محتمل.

### مكافحة التصيد — توكن الموقع المستنسخ (Cloned Website)

أضف كود JavaScript في صفحة تسجيل الدخول الأصلية يرسل طلباً إلى `canarytokens.com/...` إذا كان عنوان الصفحة لا يطابق نطاقك الأصلي. إذا تم استنساخ الصفحة في أدوات التصيد، فستصلك إشارة فورية مع رابط موقع التصيد.

```html
<script src="https://canarytokens.com/.../submit.js"></script>
```

### إشارة "للمهاجمين فقط" (Bad-actor-only signal)

بما أن المستخدمين الحقيقيين لا يلمسون هذه التوكنز، فإن نسبة التنبيهات الخاطئة (False Positives) تكاد تكون صفراً. أي تنبيه يجب التعامل معه كنشاط عدائي مؤكد.

## استكشاف الأخطاء وإصلاحها (Fixes)

| العرض | الحل |
|---------|-----|
| مفاتيح AWS تتفعل أثناء مراجعة الكود البرمجية | صنف التوكن كـ "معروف" لفريق التطوير؛ التنبيهات من خارج نطاق IP الفريق هي الحقيقية |
| توكن PDF لا يعمل | بعض المتصفحات تمنع المصادر الخارجية افتراضياً؛ استخدم مستند Word بدلاً منه |
| تنبيهات البريد تصنف كـ Spam | استخدم الاستضافة الذاتية بنطاقك الخاص، أو اعتمد على الـ Webhook مباشرة |
| التوكن يقود الم مهاجم إلى مستلم التنبيه | استخدم بريداً إلكترونياً عاماً لكل برنامج أمني بدلاً من بريد شخصي |

## منظور المدافع (Defender perspective)

توفر Canarytokens قدرة على **كشف الخداع (Deception Detection)** بتكلفة شبه معدومة. يمكن تشغيل ثلاثة برامج:

1. **البرنامج الساكن (Static)**: نثر التوكنز في كل مكان والتنبيه عند أي لمس.
2. **البرنامج المستهدف (Targeted)**: وضع توكن فريد في أماكن لا يلمسها إلا دور وظيفي محدد (مدير نظام، محاسب)، مما يساعد في كشف التحرك الجانبي (Lateral Movement).
3. **مستند الخداع (Honey-document)**: عند تسريب المهاجم للمستندات (Exfiltration)، يقوم المستند بتنبيهك بمجرد فتحه في بيئة المهاجم، مما يوفر IP لغايات التحقيق الجنائي.

يمكن دمجها مع **Canary** (أجهزة الخداع المادية من Thinkst) لعمليات خداع أكثر تعقيداً مثل خوادم الملفات الوهمية أو بيئات Active Directory كاملة.

## أمن العمليات للمدافع (OPSEC)

- تجنب إدراج أسرار تبدو حقيقية جداً لدرجة قد تجعل ماسحات الأمان الخاصة بالموردين (Security Scanners) تطلق تنبيهات خاطئة خارجية.
- توثيق **أي توكنز موجودة ولماذا** في دليل إجراءات الاستجابة للحوادث (IR runbook)؛ لا ينبغي للمحلل أن يفاجأ بتنبيه دون معرفة مصدره.
- لا تخزن قائمة التوكنز في نفس المكان الذي وضعت فيه التوكنز (حتى لا يكتشف المهاجم الكمائن عند اختراقه للنظام).
